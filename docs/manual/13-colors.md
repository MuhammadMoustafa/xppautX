# Colors

The colors used in individual curves take on numbers from 0 to 10. Here is the meaning of the numbers:

**0-Black/White; 1-Red; 2-Red Orange; 3-Orange; 4-Yellow Orange; 5-Yellow; 6-Yellow Green; 7-Green; 8-Blue Green; 9-Blue; 10-Purple.**

**In web2** these eleven indices (0 the foreground colour, then red through purple) map to a palette per theme (`plot/colors.ts`), keeping the hue named above; see [Using the interface](04-using-the-interface.md) for the light/dark/system theme.
