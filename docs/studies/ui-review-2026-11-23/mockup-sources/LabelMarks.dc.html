W863 · Every label type has its own mark

Today 27 types share 8 shapes. A triangle is LP, LPC, CP, LPNS or R2, and a bar is six different ends. Twenty-seven shapes nobody could remember would not help either. The proposal is one rule: the shape gives the kind of point, the fill says what it lies on, and the code is drawn beside every special point.
• Filled means an equilibrium label and hollow means a cycle label: LP ▲ against LPC △, BP ◆ against BPC ◇.
• A small square is a two-parameter (codimension-two) point, and its code names it.
• A bar is where a branch ended, and its code says how (EP, SNIC, HOC, …).
• Output points keep a faint dot with no number. The number shows on hover or Grab.
The key lists only the types the diagram has. Marks and codes are the same at every width, so this sheet shows them once, in light and dark.
