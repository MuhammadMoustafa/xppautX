# The session tools/webtest.mjs plays in the browser: lecar.ode started
# with -anifile gui_test.ani, 1280x860. One step per line:
#   key K...              key presses (xppaut names: Escape, Enter, ArrowUp...)
#   click TARGET          a button, tab or list item by its text, or css=SELECTOR (no spaces)
#   clickat TARGET X Y    a click at X,Y inside the element
#   drag TARGET X1 Y1 X2 Y2
#   type TEXT             into the focused field (a new dialog focuses and selects its first)
#   set css=SELECTOR VALUE  a field's value, as if typed and left
#   expect [!]TARGET      TARGET (css=SELECTOR or visible text) is, or with !, is not present
#   size W H | wait MS | eval JS
# Every step waits until the client is idle or waiting in a prompt. A thrown
# error (expect not finding its target, or eval throwing) fails the step and
# is reported; the session moves on to the next step regardless. Tests check
# data, never pixels: `eval` is how a step asserts what used to be a
# screenshot — a dialog's kind and title, a value the server computed, a
# canvas actually drawn to (colorCount above the axes-only baseline, not a
# comparison against another build), client state fields.
